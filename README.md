# 🕵️‍♂️ Detetive de Fake News

Uma aplicação web interativa desenvolvida como projeto escolar/acadêmico (Projeto Filosofia) para conscientização e combate à desinformação. O **Detetive de Fake News** permite que os usuários verifiquem a veracidade de notícias locais por meio de uma simulação de análise em um banco de dados interno.

---

## 🚀 Sobre o Projeto

O projeto nasceu com o propósito de unir tecnologia e reflexão crítica sobre o impacto das *fake news* na sociedade. A página oferece uma interface amigável e direta, onde o usuário pode ler dicas de como identificar notícias falsas e validar manchetes em tempo real.

---

## 🛠️ Tecnologias Utilizadas

O projeto foi construído utilizando tecnologias web fundamentais (Front-End básico):

* **HTML5:** Estruturação semântica das seções da página.
* **CSS3:** Estilização responsiva utilizando **CSS Grid** e **Flexbox**, além da fonte *Poppins* via Google Fonts.
* **JavaScript (Vanilla):** Lógica de busca e filtragem no "banco de dados" simulado com retorno dinâmico via alertas.

---

## 💡 Funcionalidades

* **Validação de Manchetes:** O usuário digita o título de uma notícia e o sistema busca correspondências no sistema.
* **Simulação de Análise:** Utiliza um temporizador (`setTimeout`) de 3 segundos para simular o processo de checagem em background.
* **Responsividade:** Design adaptável para diferentes tamanhos de tela (computadores, tablets e celulares) usando técnicas modernas de layout.
* **Central de Dicas:** Cards informativos para educar o usuário sobre boas práticas de navegação na internet.

## 📦 Como Executar o Projeto

Para rodar o projeto localmente, você não precisa instalar nenhuma dependência complexa. Basta seguir os passos:

1. Faça o clone deste repositório:
```bash
git clone https://github.com/seu-usuario/detetive-fake-news.git

```


2. Navegue até a pasta do projeto.
3. Abra o arquivo `index.html` diretamente em qualquer navegador web de sua preferência.

> ⚠️ **Nota de Desenvolvimento:** Certifique-se de que o caminho do arquivo JavaScript no seu `index.html` esteja correto em relação à estrutura das suas pastas!
